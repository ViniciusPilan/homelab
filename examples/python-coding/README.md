# Python coding script
## What it does
This script get the html content from a set of endpoints.

## Why this was created
This was created to be an example in python scripting in this repository.

## How to run:
```sh
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -r requirements.txt
$ python3 main.py
```

## Requirements
- requests lib must be intalled
- internet connection

There is a `requirements.txt` file in this directory to show all the required libs.

## Input
No input is required.

## Output
The HTML content of each page defined at the constante ENDPOINTS.
